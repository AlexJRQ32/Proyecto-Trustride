# Este es un README explicativo

## Descripcion de la App:

Esta va a ser una app en la cual podras contratar a un paseador de mascotas para que pasee tu mascota, ideal para personas que tienen mascotas pero no tienen tiempo para sacarlas a pasear ellos mismos.

## Stack Tecnologico:

- Base de Datos: SQL Server
- Backend: .NET Core Web API
- Frontend: React + Vite
- Deployment DB y Backend: Somee Inicialmente, luego queda por definir 
- Deployment Frontend: Vercel
- Dominio: (Por definir)

## Arquitectura:

- Modular basada en Features.
