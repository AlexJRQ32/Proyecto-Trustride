Diagrama de Base de Datos · SQL Server + .NET Core + EF Core

SQL Server .NET Core Web API Entity Framework Core
ℹ️ Users se vincula a AspNetUsers de ASP.NET Core Identity (PK = UNIQUEIDENTIFIER compartido). Enums como TINYINT mapeado con EF Core HasConversion<int>(). PKs internas como INT IDENTITY.
